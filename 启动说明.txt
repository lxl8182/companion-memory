铃芽 RIN · 一键启动
====================

首次使用
--------
1. 双击  start.cmd
   首次会自动生成配置模板，并启动服务与管理台。
   浏览器打开 http://127.0.0.1:48931/

2. 在管理台里配置模型
   设置 → 模型接口 → 填 接口地址 / API Key / 对话模型 → 保存并应用
   （保存即生效，不需要重启，也不用设环境变量）

日常
----
  start.cmd     启动（已在运行则直接复用，不会起第二份）
  stop.cmd      停止（等服务真正退出、端口释放后才返回）
  status        在命令行执行：start.cmd status

数据与日志
----------
  运行根   ..\companion-runtime  配置     ..\companion-runtime\config\stack.toml
  记忆     ..\companion-runtime\memory  日志     ..\companion-runtime\logs\memory-service.log
  模型 Key ..\companion-runtime\state\memory-service\local_state\model_config.json

  改端口/角色/超时改 stack.toml；改模型接口优先用管理台页面。

命令行参数
----------
  start.ps1 -Action start|stop|status|init
            -Config <stack.toml 路径>
            -Python <解释器路径>
            -NoOpen        启动后不自动开浏览器
